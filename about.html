About This Project

📖 Project Overview

The Digital Library Management System is a simple college mini project that helps manage a small library's book collection. It allows you to add, edit, search, and delete books, as well as issue and return them — all from your browser.

🎯 Features

  • Dashboard — View total, available, and issued book counts at a glance.
  • Book Catalog — Add, edit, search, and delete books easily.
  • Issue / Return — Mark books as issued to a borrower or return them.
  • Persistent Data — All records are stored in the browser's localStorage.
  • Sample Data — Pre-loaded books so you can explore right away.

🛠️ Technologies Used

  • HTML5
  • CSS3
  • JavaScript (Vanilla / Plain JS)
  • Browser localStorage for data storage

📁 File Structure

  • index.html — Dashboard page
  • books.html — Book Catalog page
  • issue-return.html — Issue / Return page
  • about.html — About page (this page)
  • style.css — Stylesheet for all pages
  • script.js — JavaScript logic for all pages
  • README.md — Documentation

👨‍🎓 Developed For

This project was developed as a college mini project to demonstrate basic front-end web development skills using only HTML, CSS, and JavaScript — with no server, database, or login system required.
